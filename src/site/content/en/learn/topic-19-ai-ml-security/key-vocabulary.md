# Key Vocabulary — Topic 19: AI/ML Security & LLM Red Teaming

| Term | IPA | Meaning (Tiếng Việt) | Technical Context |
|---|---|---|---|
| **adversarial** | /ˌæd.vɚˈser.i.əl/ | Đối kháng, thù địch | *Adversarial machine learning focuses on crafting inputs designed to fool models.* |
| **vulnerability** | /ˌvʌl.nɚ.əˈbɪl.ə.t̬i/ | Lỗ hổng bảo mật | *Prompt injection is the top critical vulnerability in LLM applications.* |
| **prompt injection** | /prɑːmpt ɪnˈdʒek.ʃən/ | Tấn công chèn prompt | *Direct and indirect prompt injection manipulate the model's instruction flow.* |
| **jailbreak** | /ˈdʒeɪl.breɪk/ | Phá rào cản an toàn | *Jailbreaking bypasses system safety filters to generate harmful outputs.* |
| **data poisoning** | /ˈdeɪ.t̬ə ˈpɔɪ.zən.ɪŋ/ | Đầu độc dữ liệu huấn luyện | *Poisoning attacks inject malicious triggers into fine-tuning datasets.* |
| **model inversion** | /ˈmɑː.dəl ɪnˈvɝː.ʒən/ | Đảo ngược mô hình | *Model inversion attempts to reconstruct private training samples from logits.* |
| **membership inference** | /ˈmem.bɚ.ʃɪp ˈɪn.fɚ.əns/ | Suy luận thành viên dữ liệu | *Determining if a specific person's record was used in training.* |
| **sandboxing** | /ˈsænd.bɑːk.sɪŋ/ | Cô lập môi trường thực thi | *All agent tool and code execution must run inside an isolated sandbox.* |
| **privilege escalation** | /ˈprɪv.əl.ɪdʒ ˌes.kəˈleɪ.ʃən/ | Leo thang đặc quyền | *Preventing autonomous agents from gaining unauthorized administrative access.* |
| **defense-in-depth** | /dɪˈfens ɪn depθ/ | Phòng thủ theo chiều sâu | *Employing multiple redundant security layers rather than a single perimeter.* |
| **sanitization** | /ˌsæn.ə.t̬əˈzeɪ.ʃən/ | Khử khuẩn / Làm sạch dữ liệu | *Input and output sanitization strips malicious shell commands or scripts.* |
| **red teaming** | /red ˈtiː.mɪŋ/ | Đội đỏ (Kiểm thử tấn công) | *Simulating adversary tactics to discover zero-day vulnerabilities in AI.* |
| **fuzzing** | /ˈfʌz.ɪŋ/ | Kiểm thử tự động đột biến | *Automated fuzzing feeds mutated adversarial prompts to test boundary robustness.* |
| **governance** | /ˈɡʌv.ɚ.nəns/ | Quản trị và tuân thủ | *AI governance ensures alignment with NIST AI RMF and regulatory standards.* |
| **provenance** | /ˈprɑː.və.nəns/ | Nguồn gốc xuất xứ dữ liệu | *Validating cryptographic provenance for external datasets and base models.* |
| **mitigation** | /ˌmɪt̬.əˈɡeɪ.ʃən/ | Biện pháp giảm thiểu | *Implementing dual-LLM guardrails is an effective mitigation strategy.* |
