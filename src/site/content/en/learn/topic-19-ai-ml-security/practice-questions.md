# Practice Questions — Topic 19: AI/ML Security & LLM Red Teaming

## Technical Interview & Discussion Questions

1. **Threat Modeling:** "How would you model the security attack surface of an enterprise RAG system that ingests external web pages and runs autonomous database queries?"
2. **Prompt Injection:** "What is the difference between direct and indirect prompt injection, and why can't regular expressions or naive blocklists solve prompt injection completely?"
3. **Agent Security:** "When deploying an AI agent with tool-calling capabilities (e.g. bash execution, API access), what guardrails do you implement to prevent privilege escalation?"
4. **Data Poisoning:** "How do you detect and mitigate clean-label data poisoning attacks in continuous fine-tuning pipelines?"
5. **Privacy & Extraction:** "Explain how membership inference attacks work against fine-tuned LLMs and what differential privacy techniques can protect sensitive user data."
6. **Defense-in-Depth:** "Walk me through the architecture of a production AI Security Gateway. How do you balance latency, false-positive rates, and safety enforcement?"
7. **Compliance:** "How do you map your AI application's security controls to the NIST AI Risk Management Framework (AI RMF) and OWASP Top 10 for LLMs?"
