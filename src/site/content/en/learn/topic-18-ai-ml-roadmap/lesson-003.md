## Goal

Run the full supervised-learning workflow: data → features → model → evaluation.

{% vi %}
**Mục tiêu:** Chạy trọn quy trình học có giám sát: dữ liệu → đặc trưng → model → đánh giá.
{% endvi %}

## What to learn

- **Supervised learning**: regression vs classification.
- Core algorithms: linear/logistic regression, decision trees, random forests, gradient boosting.
- **Train/validation/test split**, overfitting, and cross-validation.
- **Metrics**: accuracy, precision/recall, F1, ROC-AUC, RMSE.
- A touch of **unsupervised learning**: clustering, dimensionality reduction (PCA).

{% vi %}
**Học gì:**
- **Học có giám sát**: hồi quy so với phân loại.
- Thuật toán cốt lõi: linear/logistic regression, cây quyết định, random forest, gradient boosting.
- **Chia train/validation/test**, overfitting, và cross-validation.
- **Chỉ số**: accuracy, precision/recall, F1, ROC-AUC, RMSE.
- Một chút **học không giám sát**: clustering, giảm chiều (PCA).
{% endvi %}

## Build

Pick a Kaggle beginner dataset (e.g. Titanic or housing prices). Train two models, compare metrics, and write one paragraph on why one won.

{% vi %}
**Thực hành:** Chọn một bộ dữ liệu Kaggle cho người mới (vd Titanic hoặc giá nhà). Huấn luyện hai model, so sánh chỉ số, và viết một đoạn giải thích vì sao model này thắng.
{% endvi %}

## Reflection

Did your model truly generalize, or did it just memorize the training data?

{% vi %}
**Tự ngẫm:** Model của bạn có thực sự tổng quát hóa, hay chỉ học thuộc dữ liệu huấn luyện?
