## Goal

Be comfortable with the everyday tools: notebooks, NumPy, pandas, and a reproducible environment.

{% vi %}
**Mục tiêu:** Thành thạo các công cụ hằng ngày: notebook, NumPy, pandas, và một môi trường tái lập được.
{% endvi %}

## What to learn

- Python refresher: functions, comprehensions, typing, virtual environments.
- **NumPy** arrays and vectorized operations.
- **pandas** for loading, cleaning, and exploring data.
- **matplotlib** for basic plots.
- Notebooks (Jupyter / Colab) and how to keep work reproducible (`requirements.txt`).

{% vi %}
**Học gì:**
- Ôn Python: hàm, comprehension, type hint, môi trường ảo.
- **NumPy**: mảng và phép toán vector hóa.
- **pandas**: nạp, làm sạch, khám phá dữ liệu.
- **matplotlib**: vẽ biểu đồ cơ bản.
- Notebook (Jupyter / Colab) và cách giữ công việc tái lập được (`requirements.txt`).
{% endvi %}

## Build

Load a public CSV dataset in Colab, clean it with pandas, and produce three plots that answer one question about the data.

{% vi %}
**Thực hành:** Nạp một bộ dữ liệu CSV công khai trong Colab, làm sạch bằng pandas, và tạo ba biểu đồ trả lời một câu hỏi về dữ liệu.
{% endvi %}
