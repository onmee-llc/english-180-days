## Goal

Prove your AI service is good, reliable, and affordable — then package it as portfolio evidence.

{% vi %}
**Mục tiêu:** Chứng minh dịch vụ AI của bạn tốt, tin cậy, và hợp túi tiền — rồi đóng gói nó thành bằng chứng portfolio.
{% endvi %}

## What to learn

- **Evaluation**: build a small test set; use exact metrics where possible and an LLM-as-judge for open-ended quality.
- **Monitoring**: track latency, error rate, and token cost per request (KPI 1 evidence).
- **Cost control**: model selection, caching, prompt size, and a hard budget cap.
- **Guardrails**: handle bad input, prompt injection, and unsafe output.
- **Capstone**: a documented end-to-end project you can demo and put on LinkedIn/GitHub.

{% vi %}
**Học gì:**
- **Đánh giá**: dựng một bộ test nhỏ; dùng chỉ số chính xác khi có thể và LLM-làm-giám-khảo cho chất lượng mở.
- **Giám sát**: theo dõi latency, tỷ lệ lỗi, và chi phí token mỗi request (bằng chứng KPI 1).
- **Kiểm soát chi phí**: chọn model, caching, kích thước prompt, và trần ngân sách cứng.
- **Guardrail**: xử lý đầu vào xấu, prompt injection, và đầu ra không an toàn.
- **Capstone**: một dự án end-to-end có tài liệu để demo và đưa lên LinkedIn/GitHub.
{% endvi %}

## Build
